# Ubuntu Archive 🌍

**Preserving African stories for future generations.**

## About the Project

Ubuntu Archive is a web application designed to preserve, discover, and share African stories, folklore, legends, and cultural heritage. The goal is to create a digital space where these stories can be explored and passed on to future generations.

## Features

- A homepage with navigation to different sections of the website.
- A Stories page featuring African folktales and legends.
- Dedicated pages for selected stories.
- A visual interface featuring images inspired by African culture.
- A responsive layout designed for different screen sizes.

## Technologies Used

- **Python** – Backend programming.
- **Flask** – Web application framework.
- **HTML** – Website structure.
- **CSS** – Styling and layout.
- **JavaScript** – Frontend interactivity.

## Planned Features

- User registration and login.
- Uploading and sharing stories.
- Searching for stories.
- Audio storytelling.
- Likes and comments.
- User profiles.

## Project Status

🚧 **In Progress**

Ubuntu Archive is a personal development project. New features and improvements will be added as development continues.

## My Goal

To build a useful and accessible platform that celebrates African storytelling, preserves cultural heritage, and makes these stories easier for future generations to discover.
